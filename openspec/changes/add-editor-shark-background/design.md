# Design

## Context

输入卡使用 SwiftUI 容器和透明 AppKit 编辑器，实际文字与组词变化由 NSTextView 管理。两种背景复用现有窗口暂停／恢复及编辑活动通知，不把装饰状态放进 LauncherSession。

## Goals / Non-Goals

**Goals:** 可选择的小猫、鲨鱼和关闭；细节清楚、动作安静，保护文字和原生交互。

**Non-Goals:** 不移植外部美术、不新增 WebView、网络、权限、草稿保存或海底场景。

## Decisions

1. `editorBackgroundStyle` 通过两端 `@AppStorage` 连接设置菜单和输入卡，`cat`、`shark`、`none` 独立于主题与提交动画。条件切换仅替换背景 NSView；旧视图先停止，弱引用按身份检查再清除，避免旧视图卸载断开新背景。
2. 小猫直接解析三行等宽 ASCII 字符稿，用 CoreText 绘制真实字形，不描摹曲线或使用插画。三行网格固定，脸部默认微笑，按交互在圆眼、笑脸、惊讶和眨眼之间替换字符；前爪短距离移动、尾字符轻摆，`@` 小球连续滚动。预览编译同一渲染器与动作代码。
3. `CatPerchMotion` 以显露进度和速度表达动作，使用解析临界阻尼弹簧，中途改目标保留速度。完整休息后入场随机一次：80% 约 1.3 秒探头，20% 约 1 秒、8 pt 额外抬升的小跳；收回期间重输保留已有类型。按头部、身体、前爪分别绘制同一份字符，只保留一张脸；身体原位淡出、头部从入口后缓缓显露。删空后同一张脸保持可见并轻轻收低，身体与前爪在底部原位渐显，收回期间用 `( o.o )` 圆眼，尾巴与小球在约 1.4 秒内接续恢复；动作完成后圆眼保持 2 秒，随后闭眼约 150 ms，再恢复微笑；两阶段各使用一次单次计时，等待期间不启动逐帧计时。重新输入或停止装饰时取消当前表情及后续阶段。装饰显露边界随姿势移向底部，不再吞掉回落中的脸；真实按钮即时消失，其原有字符遮挡在 280 ms 内连续解除，覆盖入场中途删空的情况。遮挡只保存相对底边的几何，不延长真实按钮生命周期；改高不重置动作进度，横坐标始终沿用右下休息位置。组词、拖选及下方卡片交互暂停拨球等小动作，让已有探头或收回轻缓完成，不调用到达终点来冒充暂停。底部空闲约 8–14 秒后触发 2.8 秒拨球；仅过渡或短动作运行 30 Hz 计时器，露头时不自动拨球。指针注视及只观察、不吞事件的本地点击监听沿用原生编辑合同，轻点在底部拨球、露头时点头。
4. 保留鲨鱼原始形体、16 节身体、连续尾波、转向和有速度上限的惯性运动。其活动覆盖全卡空白，输入后续游约 1.2 秒再渐进退边，空闲满 6 秒开始返回；删除海底绘制。
5. 原生文字、占位文字、光标、选区与 SwiftUI 控件锚点构成保护区域。小猫按当前可见姿态、前爪伸展和尾巴范围检查正文与控件，探头时鼠标范围同样排除藏住的部分，头部、身体与前爪按各自可见轮廓检查，空间不足的层整体隐藏；头部隐藏时连带隐藏身体和前爪，避免无头残片，小球独立检查；跳跃穿过目标入口时只裁掉入口保护区，让入口像台沿一样挡住身体。鲨鱼在相交处裁剪。窗口隐藏、失焦、遮挡、睡眠和模式切换沿用既有停止入口；减少动态效果保留静态小猫，增强对比度隐藏全部装饰。

## Risks / Trade-offs

- 小尺寸 ASCII 的面部细节有限 → 使用同源浅深色预览检查字符形体、表情、拨球和露头状态；真实窗口观感单独说明。
- 文字布局变化 → 缓存保护区域并在编辑、选区、滚动及布局后失效，缺少排版时保守隐藏。
- 鼠标或背景切换影响输入 → 保留原事件，不替换编辑器，运行相关现有测试；真实指针、组词和偏好切换体验未实测时不标记通过。
