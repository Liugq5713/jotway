# 功能想法

记录以后想实现的功能；这里的想法尚未承诺开发，也不代表当前行为。
先写清楚场景、问题和期望，不必提前设计技术方案。
确定开发后，将对应条目迁移到 `openspec/changes/<名称>/`。

## 模板

复制下面的模板，每个想法单独一节。

```markdown
## 功能名称

- 场景：什么时候会用到？
- 问题：现在有什么不方便？
- 期望：希望实现什么效果？
- 补充（可选）：例子、参考链接或待确认的问题。
```

## 待记录的想法

## 通过 Personal Agent 创建提醒事项和日历事件

- 场景：与 Personal Agent 对话时，希望直接安排待办事项或日程。
- 问题：Personal Agent 当前只读个人事项，无法在对话中创建提醒事项或日历事件。
- 期望：通过自然语言让 Personal Agent 在 Apple Reminders 中创建提醒事项，或在 Apple Calendar 中创建日历事件。
- 补充（可选）：例如“明天下午三点提醒我交报告”或“帮我安排周五上午十点到十一点的项目讨论”。
