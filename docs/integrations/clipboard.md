# Clipboard

> Role: **Current**

Clipboard remains a registered local action with collection, settings and stored history. The manual target menu and keyboard cycle offer Apple Notes and Codex only; Clipboard has no entry there and no replacement history entry is provided. When Clipboard is the current target, its list uses the entire editor text as a query, retaining old `@clipboard` text literally. Every whitespace-separated word must match original text or cached image OCR, ignoring case; empty queries show all retained entries. A matching `@` template picker temporarily covers the results. Choosing a template only updates the local query and never copies a result. No query or history content is sent to AI or a network service. Template settings, action enablement and collection are independent.

## Collection and storage

Collection defaults on when no preference has been saved, including after an upgrade. Saved on/off choices take precedence; turning it off stays off across restarts. Manage collection in Settings → Actions → Clipboard; opening the list does not change the preference. The list has no Settings button or replacement navigation, including empty, paused and error states; collection status and errors remain visible. Action visibility and collection are independent. The app observes clipboard changes every 300 ms while running. Startup and enable establish a baseline; missed or old copies are not imported. With collection disabled, existing history remains searchable and copyable.

One version yields at most the first eligible item. PNG takes priority over TIFF, then plain text within that item. File URL items, RTF-only data, blank text, and `org.nspasteboard.TransientType`, `ConcealedType` or `AutoGeneratedType` observations are excluded. Version changes during reading are discarded. If conversion is busy, observations can be skipped; this is not an exhaustive copy audit.

The separate Application Support `Jotway/Clipboard/clipboard.sqlite` preserves original text whitespace and image bytes. Matching type, digest and bytes update recency without duplicates. Retention is at most 200 entries and 200 MiB of combined payload, text, thumbnail and OCR storage. Text is limited to 1 MiB UTF-8; each image representation to 20 MiB and 40 million decoded pixels. Oversized input is skipped with a status. Original images are never shrunk for restoration; previews are bounded to 160 pixels.

## Local image text

A saved image is available before OCR. The serial queue waits for at least two seconds without keyboard/mouse input, then launches `JotwayClipboardOCR`. It selects supported Simplified Chinese, Traditional Chinese and English languages, applies image orientation, and caps its working image at 4096 pixels. Each job has a 60-second deadline and returns at most 32 KiB of UTF-8 text. The helper exits after each job and is killed and reaped on timeout or cancellation. The main application never loads Vision. The helper has its own sandbox without inheritance and an embedded bundle identity. The parent sends at most 20 MiB through stdin, drains bounded stdout concurrently, and closes both pipes after reaping; no payload file path or broad file access is passed to the helper. See [Direct distribution runtime](../../openspec/specs/direct-distribution-runtime/spec.md).

Pending, processing, ready, empty and failed states remain distinct. Completed and empty results are reused on duplicate copies. Failed OCR does not retry indefinitely and never blocks original-image copying. Disabling, clearing or evicting invalidates work; re-enabling or restarting resumes interrupted pending work. Query edits do not create OCR jobs. Results require a current history generation, ID, digest and OCR version.

## Selection, copy, and failure

The lower list is 300 pt high by default, shrinks to available panel space and scrolls internally. Arrow keys and clicks select by stable ID. Query changes choose the first match; background changes preserve a surviving selection, otherwise clear it until explicit navigation or a new query. VoiceOver labels include text summaries or image dimensions, OCR and selection state. Marked text receives input-method keys before navigation or confirmation.

Enter or Command+Enter freezes selection and copies full text or the stored PNG/TIFF bytes. Success clears the query, hides the panel and returns to the previous application. It never sends a paste key. Failed payload reads leave the current clipboard intact; failed writes retain the query and show failure. Repeated confirmation cannot copy a second item. Own restore writes are excluded from history, OCR and recent text quotes; subsequent external copies remain eligible.

Clear history requires confirmation. It immediately invalidates the list and background results, removes the database and sidecars, and leaves the current clipboard unchanged. It does not re-import that unchanged clipboard. Storage errors remain visible and pause collection; toggling collection retries. No in-memory fallback is presented as persisted history.
