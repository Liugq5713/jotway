拿到发行包后

  1. 下载并打开 DMG。下载地址与 SHA-256 校验值会随正式产物一同提供。
  2. 拖入 Applications。把磁盘映像中的 Jotway.app 拖到“应用程序”，随后推出磁盘映像。
  3. 完成首次设置。打开 Jotway，设置自己的全局快捷键。界面当前使用英文，输入支持中文。
  4. 按需授予权限。在 Settings → Actions 选择备忘录文件夹、提醒事项列表或日历，只授予所用 Action 需要的权限。

从源码开始

现在也可以从公开仓库自行构建。需要 Swift 6.2 与 macOS 26 SDK；应用最低支持的系统由构建产物记录。

git clone https://github.com/Liugq5713/jotway.git
cd jotway
./scripts/build-app.sh

构建命令会生成本地 Jotway.app。查看构建说明 ↗
