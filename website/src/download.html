When a release is available

  1. Download and open the DMG.The download link and SHA-256 checksum will appear with the verified release.
  2. Move Jotway to Applications.Drag Jotway.app from the disk image into Applications, then eject the disk image.
  3. Set your shortcut.Open Jotway and follow the first-use guide. The interface is in English; your input can be in other languages.
  4. Grant permissions as needed.In Settings → Actions, select a Notes folder, Reminders list, or calendar. Grant only the permissions required by the Actions you use.

Build from source

You can build Jotway from its public repository today. Development requires Swift 6.2 and the macOS 26 SDK. Each release records its minimum supported macOS version.

git clone https://github.com/Liugq5713/jotway.git
cd jotway
./scripts/build-app.sh

This creates a local Jotway.app. Read the build guide ↗
