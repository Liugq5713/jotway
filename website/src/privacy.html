隐私与数据流

你的文字，
会去哪里。

草稿、Action、可选 AI 和本地反馈，各有自己的边界。这里说明当前实现如何处理它们。

01 · 先留在这台 Mac 上

尚未执行的草稿保留在当前应用进程的内存中。隐藏面板后可以继续编辑；退出、崩溃或重启会清空。执行失败时会恢复原草稿；已有新草稿时，失败提交会在本次进程内单独保留，等待你恢复。

Action 配置、偏好、应用使用统计和意图反馈在本机保存。偏好使用 UserDefaults；数据库位于 Jotway 的 Application Support 目录。API Key 存在本机仅当前用户可访问的凭证文件中，并非云端同步或系统钥匙串。

Jotway 不提供可浏览的收件箱、内容历史、Summary 或内容导出归档。数据模型 ↗

02 · 确认后交给选中的 Action

Notes、Reminders 和 Calendar 会把确认后的正文写入你配置的目标；目标应用是否通过 iCloud 或其他账户同步，取决于你在那些应用中的设置。

Google Search 会把正文放入 Google 搜索 URL，并交给 Chrome 打开。应用启动匹配在本地完成。ChatGPT Action 会把正文交给兼容的桌面应用预填到对话输入框，需要你在目标应用中手动发送；Jotway 不要求 OpenAI API Key，也不能确认远端模型是否收到正文。其他 Action 的行为请查看 当前产品说明；Jotway 无法替目标应用清除已接收的内容。

03 · 可选的网络处理

AI 功能需要单独配置。提供方可能按你的账户计费；其服务器上的保留、使用和删除规则由提供方决定。以下本地清除操作不会撤回已发送的请求。

Jev / TypeSafe · 意图识别

保存 Jev Key 后，符合长度限制的草稿会在输入阶段连同可用 Action 的识别条件发送给 TypeSafe，不需要等到按 Enter 才发送。返回结果只建议目标；确认仍由你完成。没有 Key 或请求失败时，继续使用本地规则、手动选择与可用的默认 Action。

在 Settings → Intent Recognition 移除 Key，可停止之后的模型识别请求。请求边界 ↗

DeepSeek · Action 文字整理

Notes、Reminders 与 Calendar 独立开启整理后，确认执行会将正文、整理指令及必要的日期上下文发送给 DeepSeek。该路径固定使用 DeepSeek，不跟随通用 AI 来源选择。缺少 Key、网络错误、超时或输出无效时，回退到原文；日期按对应 Action 的默认值处理。

在 Settings → Actions 关闭对应 Action 的 AI rewrite，或在 Settings → AI 选择 DeepSeek 后移除 Key。AI 能力说明 ↗

DeepSeek / Moonshot · 通用 AI 配置

AI 设置页注册这两个来源，可以保存模型、Key 与指令。连接测试发送固定示例，不发送当前草稿。选择 Moonshot 不会把上述 Action 整理路径切换到 Moonshot。

在 Settings → AI 选择相应来源后移除其 Key。设置变化只影响新请求，已入队或正在处理的请求使用开始时的配置。配置与连接测试 ↗

04 · 本地反馈会保留完整正文

确认路由时，Jotway 可能保存含完整草稿正文的本地意图反馈。这与只在内存中保留的未提交草稿不同，也不构成可浏览的内容历史。反馈不会上传用于训练，也不会自动修改路由规则。

纠正样本
你改变 Jev 建议目标并确认后，保留最近 200 条。可在 Settings → Intent Recognition 清除。
已接受的建议样本
当前没有保留期限、条数上限或用户界面中的清除入口。退出应用、清除纠正样本或清除日志，都不会删除这些样本。
应用使用统计
保存应用路径、累计打开次数与最近打开时间，不是逐次活动历史。当前也没有单独的用户界面清除入口。

05 · 日志与密钥如何清理

运行日志记录受限的阶段、结果、标识与耗时，不记录草稿正文、API Key、完整提供方响应或账户详情。保留今天及之前六天，单文件最多 10 MB，总量最多 50 MB。

Settings → General → Runtime Logs 可以打开、导出或清除保留日志；导出含当前 Jev 规则定义。清除日志不会清除草稿、偏好或本地反馈。AI 与 Jev 页面分别移除对应 Key；移除 Key 不会删除已有反馈或远端数据。当前没有统一的“一键清空全部数据”功能。

06 · 这个网站

本站是静态页面，没有账号系统、统计脚本或第三方字体请求。面板外观切换只作用于当前页面，不保存偏好。访问 GitHub、下载文件或跟随其他外部链接后，请同时留意相应服务的数据处理规则。
