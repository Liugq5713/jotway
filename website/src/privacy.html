PRIVACY & DATA FLOW

Where your
words go.

Drafts, Actions, optional AI, and local feedback have different boundaries. Here's what the current app does with each.

01 · On your Mac

An unsubmitted draft lives in the current app process's memory. Hide the panel and return to it during the same session. Quitting, a crash, or a restart clears it. A failed Action restores the draft; if you have started a new one, the failed submission waits separately in memory for you to restore it.

Action configuration, preferences, app usage statistics, and intent feedback are stored locally. Preferences use UserDefaults. The database lives in Jotway's Application Support directory. API keys use local credential files with access restricted to your user account; they are not stored in the system Keychain or synced by Jotway.

Jotway has no browsable inbox, content history, Summary, or content export archive. Read the data model ↗

02 · After you confirm an Action

Notes, Reminders, and Calendar receive the confirmed text in your chosen destination. Whether those apps sync it through iCloud or another account depends on their settings.

Google Search puts your text in a Google search URL and opens it in Chrome. App launching is matched locally.

See the product guide for the complete Action list. Jotway cannot delete content already received by another app.

03 · Optional network processing

AI features need separate configuration. Providers may charge your account and apply their own server-side retention, use, and deletion policies. Clearing local data does not retract a request already sent.

Jev / TypeSafe · Intent recognition

After you save a Jev key, eligible drafts are sent to TypeSafe with criteria for available Actions while you type. This can happen before you press Enter. The response only suggests a destination. Without a key, or when a request fails, local rules, manual selection, and the available fallback remain usable.

Remove the key in Settings → Intent Recognition to stop future model requests. Read the request boundary ↗

DeepSeek · Action text processing

When processing is enabled for Notes, Reminders, or Calendar, confirming that Action sends the text, processing instructions, and relevant date context to DeepSeek. This path uses DeepSeek regardless of the general AI source selection. A missing key, network error, timeout, or invalid response falls back to the original text and the Action's default dates.

Disable AI rewriting for the Action in Settings → Actions, or select DeepSeek in Settings → AI and remove its key. Read about AI processing ↗

DeepSeek / Moonshot · General AI settings

The AI settings register both providers and store your model, key, and instructions. Connection tests send fixed sample content, not your current draft. Selecting Moonshot does not switch the Action text-processing path above to Moonshot.

Select the provider in Settings → AI to remove its key. Changes affect new requests; queued or running requests use the configuration captured when they started. Read about configuration and tests ↗

04 · Local feedback can include the full text

Confirming a route may save local intent-feedback samples containing the entire draft. These samples are separate from unsubmitted, memory-only drafts. They are not a browsable content history, are not uploaded for training, and do not automatically change routing rules.

Corrections
When you change a Jev suggestion and confirm, Jotway keeps the most recent 200 corrections. Clear them in Settings → Intent Recognition.
Accepted suggestions
There is currently no retention period, record limit, or user-facing clear control. Quitting the app, clearing corrections, or clearing logs does not remove these samples.
App usage statistics
App paths, cumulative open counts, and the most recent open time are stored locally. This is not a per-event activity history. There is no separate user-facing clear control.

05 · Clearing logs and keys

Runtime logs contain bounded stages, outcomes, identifiers, and timings. They exclude draft text, API keys, full provider responses, and account details. Logs retain today and the previous six days, with a 10 MB limit per file and 50 MB in total.

Settings → General → Runtime Logs lets you open, export, or clear retained logs. Exports include the current Jev rule definition. Clearing logs does not clear drafts, preferences, or intent feedback.

Remove provider keys in AI settings and the Jev key in Intent Recognition settings. Removing a key does not delete existing feedback or remote data. There is no single control to erase all app data. Read the logging policy ↗

06 · This website

This is a static website with no account system, analytics scripts, or external font requests. The interactive demo uses only predefined sample text. It does not open apps, send text to a provider, or save your choices. Its controls affect only the current page.

GitHub, downloads, and other external links are subject to the respective service's data policies.
